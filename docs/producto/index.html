Hilo transversal — Producto (Vitrina)

El currículo no son materias sueltas: desde M12 construyes un SaaS (software como servicio) vertical (menú + pedidos para QSR y barras de bebidas). Spec completa: producto-saas.md.

Mapa de artefactos

Materia Artefacto que deja Carpeta sugerida
M12 SRS (especificación de requisitos de software) + RNF (requisitos no funcionales) seguridad + MVP (producto mínimo viable) freeze projects/m12-srs/
M13 Diagramas + ADRs + trust boundaries projects/m13-diseno/
M14 ≥5 patrones justificados en el código projects/m14-patrones/
M15 CI (integración continua) verde + tests de dominio/auth projects/m15-calidad/
M16 Informe usabilidad + iteración UI (interfaz de usuario) projects/m16-ihc/
M17 Piloto web (1 local) + ADR (registro de decisión de arquitectura) tenant_id projects/m17-vitrina/
M18 Threat model + hardening + tests projects/m18-appsec/
M19 Deploy, secrets, backup/restore projects/m19-ops/
M20 App staff/cliente misma auth projects/m20-movil/
M21 Roadmap + sprints del SaaS projects/m21-proyectos/
M22 10 demos/trials + pricing Free/Pro projects/m22-bektor/
M23 FAQ (preguntas frecuentes)/RAG (generación aumentada por recuperación) por tenant (menú/políticas) projects/m23-ia/
M24 Spike go/no-go (opcional al core) projects/m24-emergentes/
M25 Security review cross-tenant projects/m25-ciber/
M26 SaaS en prod + Stripe test + temas + egreso projects/m26-capstone/

Reglas de oro del hilo

  1. Cada materia deja un artefacto que la siguiente puede abrir sin adivinar.
  2. El piloto (M17) es un local; el SaaS (M26) son ≥2 tenants.
  3. Seguridad y tenant_id no se “dejan para el final” — ver hilo seguridad.
  4. Comercial (M22) y técnico (M17–M26) se alimentan: demos reales sobre el producto real.
  5. El menú es el núcleo; la landing y el marketplace de temas no sustituyen pedidos ni aislamiento.

Cómo usarlo

  1. Antes de M12, lee producto-saas.
  2. En cada materia del mapa, abre la carpeta projects/mXX-* y cumple Evidencia de hecho.
  3. En M26, la rúbrica de egreso exige el hilo completo (no un CRUD (crear, leer, actualizar y borrar) suelto).
