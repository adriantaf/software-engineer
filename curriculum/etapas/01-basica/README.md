# Etapa Básica

**Objetivo:** pensar como ingeniero, programar con solidez y bases matemáticas útiles para software.

**Duración estimada:** 4–5 meses @ ≥20 h/semana.

**Materias:** M01 → M06 (en orden).

| ID | Materia | Semanas | Horas |
|----|---------|---------|-------|
| M01 | [Método, Git, Linux y documentación](M01-metodo-y-herramientas.md) | 2 | 40 |
| M02 | [Programación I (TypeScript)](M02-programacion-i.md) | 6 | 120 |
| M03 | [Matemáticas discretas](M03-matematicas-discretas.md) | 5 | 100 |
| M04 | [Probabilidad y estadística aplicada](M04-probabilidad-estadistica.md) | 4 | 80 |
| M05 | [Organización de computadoras](M05-organizacion-computadoras.md) | 3 | 60 |
| M06 | [Programación II (OO, tipos y errores)](M06-programacion-ii.md) | 5 | 100 |

**Criterio para pasar a Disciplinaria:** M01–M06 con prácticas y proyectos marcados; puedes explicar Git branching, tipos en TS, un algoritmo básico de complejidad, y un modelo estadístico simple sin tutorial.

Antes de empezar: lee [Cómo estudiar](../../como-estudiar.md). Cada materia de esta etapa incluye **Día 1**, ejemplos y errores comunes.
