# L17 — Outreach semana 5 — lote de cinco contactos

**~5 h · Semana 5**

Vendes suscripción SaaS, no agencia. Hoy entregas **`projects/m22-bektor/outreach-semana-05.md`**. Sin ese artefacto en git, la lección no cuenta para el dominio de M22.

## Objetivo

Contactar 5 negocios del ICP con secuencia (mensaje → seguimiento → demo offer).

## Por qué empieza así

Semana 5 exige volumen disciplinado, no heroísmo aleatorio.

Conceptos que debes poder explicar al cerrar:

- Secuencia.
- Personalización mínima.
- Canal.
- Tasa respuesta.

## Pasos (hazlos en orden)

### 1. Lectura concreta de la fuente (40–60 min)

Lee en *El método Lean Startup* (ed. ES) lo indicado: _Lean — motor de crecimiento (intro)_.

Traduce a Vitrina: 5 bullets en `projects/m22-bektor/bitacora-m22.md` con una **acción** comercial de esta lección (demo, outreach, pricing).

### 2. Prepara evidencia y carpetas (20–30 min)

Confirma rutas bajo `projects/m22-bektor`.

Documenta `projects/m22-bektor/outreach-semana-05.md`: 5 contactos, mensaje enviado, respuesta, siguiente paso.

### 3. Laboratorio principal (90–120 min)

Objetivo: ≥2 conversaciones sobre producto esta semana.

### 4. Commit atómico (15 min)

```bash
git add projects/ curriculum/etapas/03-terminal/ || git add projects/
git status
git commit -m "docs(m22): l17 outreach-semana-5-lote-de-cinco-contacto"
```

El mensaje debe mencionar el artefacto de hoy; no mezcles lecciones distintas en el mismo commit.

## Hecho cuando

Marca la lección **solo si**:

1. Existe el entregable: `projects/m22-bektor/outreach-semana-05.md`.
2. 5 contactos documentados.
3. ≥2 conversaciones producto.
4. Fechas reales.
5. Commit `docs(m22): l17 …` en el historial.
