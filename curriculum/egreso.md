# Rúbrica de egreso competente (titulación interna)

No es título oficial. Es la meta de dominio de esta academia. Debes cumplir **todas** las evidencias.

## Checklist

- [ ] **Sistema web en producción:** auth, base de datos, roles, tests, CI, deploy, backups.
- [ ] **SRS + diseño** (diagramas) de un negocio real o simulado serio, con historial de cambios.
- [ ] **App móvil o desktop** conectada al mismo backend.
- [ ] **Informe de seguridad** (amenazas OWASP mitigadas en tu producto).
- [ ] **Portfolio de estructuras de datos y algoritmos** (implementación propia + complejidad explicada).
- [ ] **10 conversaciones comerciales** documentadas + al menos 1 piloto pagado o carta de intención.
- [ ] **Video o demo en vivo** explicando arquitectura y trade-offs **sin leer un tutorial**.
- [ ] **Inglés:** progreso documentado hacia B1 lectura técnica (alineado a requisito UABC).

## Entregables del proyecto integrador (M25)

1. Repositorio público del producto.
2. Memoria técnica (PDF o Markdown): problema, usuarios, arquitectura, decisiones, métricas.
3. URL en producción + instructivo de despliegue.
4. Suite de tests con coverage mínimo acordado (backend ≥70% en lógica de negocio).
5. Registro de demos/clientes en `projects/m25-capstone/`.

## Criterio de “aprobado”

El mentor (o tú con honestidad brutal) solo marca egreso si puedes construir un CRUD con auth + deploy + tests **desde cero en un fin de semana** sin tutorial paso a paso, y explicar el porqué de cada decisión.
