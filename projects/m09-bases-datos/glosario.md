# Glosario — dominio Agenda Ops (M09)

| Término | Definición en este producto | No confundir con |
|---------|----------------------------|------------------|
| Cliente | Persona que reserva un servicio | Usuario staff / owner del SaaS |
| Servicio | Ítem del catálogo con duración y precio | “Microservicio” de software |
| Cita | Reserva con inicio/fin y estado | Evento genérico de calendario |
| Tenant | Negocio suscriptor (columna preparada) | Cliente final del salón |
| No-show | Cita no asistida sin cancelar a tiempo | Cancelada |
| Seed | Datos demo versionados en SQL | Backup de producción |
| Migración | Cambio de esquema en git + orden | `ALTER` suelto en prod |
| Least privilege | Rol de app con grants mínimos | Usuario `postgres` en runtime |
