# Proyectos de la academia

Aquí vive la evidencia. Cada materia puede crear su carpeta `mXX-nombre/`.

## Plantillas sugeridas

- `m01-diario/` — bitácoras semanales
- `m12-srs/` — SRS del producto
- `m17-crm/` — enlace al repo del Agenda/CRM (o monorepo)
- `m22-bektor/` — demos comerciales
- `m25-capstone/` — memoria y checklist de egreso

## Regla

Si no está en git (este repo o enlace claro), **no cuenta** como hecho.
