# Definition of Done — Vitrina (M21)

Checklist mínima para cerrar un issue. Adapta; no borres el ítem de seguridad.

- [ ] Código en rama / PR (o self-review documentado)
- [ ] Tests relevantes verdes (o justificación de por qué no aplican)
- [ ] CI verde cuando el repo tiene pipeline
- [ ] Documentación en `projects/` si la lección/materia lo pide
- [ ] Staging actualizado si el cambio es deployable
- [ ] **Seguridad:** sin secretos en git; sin IDOR obvio en el cambio
- [ ] Issue actualizado con evidencia (URL, commit, captura)
